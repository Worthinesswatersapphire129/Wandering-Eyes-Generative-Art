The project uses JavaScript and the p5.js library to create visuals. Each art piece generates its own path, color palette, and geometric structure. Because the computer calculates these lines in real time, you will never see the exact same image twice. 

The stories within the art provide context for the shapes on display. These patterns transfer well to physical fabrics and clothing designs. Use the screen captures to visualize how these digital movements translate to t-shirt layouts or fashion prints.

This frees up resources for the animation engine.
